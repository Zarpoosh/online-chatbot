نحوه اجرای پروژه پیام‌رسان:
از اونجایی که پروژه من تحت وب هست  و خروجی اون فایل .EXE نیس  پروژه با دستورات زیر اجرا میشود :


1. ابتدا مطمئن شوید Node.js روی سیستم نصب است.
2. این پوشه را از حالت زیپ خارج کنید.
3. در مسیر این پوشه، ترمینال (CMD یا PowerShell) را باز کنید.
4. دستور زیر را برای نصب پکیج‌ها وارد کرده و منتظر بمانید تا کامل شود:
   npm install

5. سپس برای اجرای سرور دستور زیر را وارد کنید:
   npm run dev

6. مرورگر خود را باز کرده و به آدرس http://localhost:4000 بروید.
7. برای اینکه چند صفحه داشته باشید  یا چند کاربر همزمان بتونن استفاده کنن چند تب مرور گر باز کرده و تو هر کدوم وارد همین لینک بالا شوید
